# English for Master

English for Academic Purposes for MSc Electrical Engineering students at the University of Kufa.

## Repository structure

- `index.html` — course dashboard
- `syllabus.html` — revised 15-week syllabus
- `week01.html` — Week 1: Academic English Foundations
- `sources.html` — English resources and further reading
- `style.css` — shared Bright Academic styling

## Week 1

**Academic English Foundations: Formal Style, Register, Precision & Diagnostic Writing**

The student-facing Week 1 page includes:
- formal vs informal academic register
- Electrical Engineering examples
- precision and clarity
- hedging / cautious academic claims
- common language issues for Arabic-speaking EFL writers
- a diagnostic writing rubric
- peer review
- extra reading resources

Instructor-only presentation cues are intentionally excluded from the student-facing page.
